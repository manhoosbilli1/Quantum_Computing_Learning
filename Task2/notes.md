In this section i'll be learning about quantum algorithms 
### Computation in quantum system 
- Unlike the usual notion about computation being complex, here we are focusing on fundamental problems and their computation such as finding minimum of occurrences or unique strings 
- There is something called a query model which is a framework for developing solutions for problems in computation; it calculates the efficiency of the computation by the number of queries made by the function block to the input. 
- There are problems such as parity where we are seeing if the bits are even or odd in the set. This can be simplified as an XOR operation given a set of bits. 
- Dutch's problem is that given a number of inputs and outputs, figuring out if the function balanced or constant. Balanced functions are where the outputs occur with equal probabilities for various outputs and constant are where single output is given with 100% of probability.
